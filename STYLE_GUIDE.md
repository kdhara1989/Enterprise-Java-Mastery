# Enterprise Java Mastery – Style Guide

## Audience

Write for Java developers with 10+ years of experience. Assume the reader already understands Java fundamentals.

## Tone

- Professional
- Technical
- Concise
- Enterprise-focused
- Production-oriented
- Decision-oriented

## Chapter Template

Every chapter must follow this structure:

1. Learning Objectives
2. Introduction
3. Why This Matters in Enterprise Applications
4. Core Concepts
5. Internal Working
6. Architecture / Design Discussion
7. Diagrams
8. Code Listings
9. Tables
10. Performance Considerations
11. Engineering Decision Record (EDR)
12. Enterprise Use Cases
13. Best Practices
14. Common Mistakes
15. Interview Questions & Answers
16. Staff Engineer Perspective
17. Summary
18. Next Chapter

Exercises must not be added.

## Code Standards

- Java 21 compatible unless explaining legacy behavior.
- Production-oriented examples.
- Prefer readable code over clever code.
- Use meaningful domain names.
- Avoid toy examples unless they clarify internals.
- Use banking, payments, insurance, retail, healthcare, logistics, telecom, or enterprise platform examples where relevant.

## Engineering Decision Record

For major topics, include:

- When to use this
- When to avoid this
- Trade-offs
- Production recommendation

## Numbering

Within each volume:

- Figures use global numbering.
- Tables use global numbering.
- Listings use global numbering.
- Do not reset numbering inside a chapter or part.
