# Enterprise Java Mastery – Governance

This document prevents drift from the approved book plan.

## Before Generating Every Chapter

Validate:

1. Roadmap Validation  
   The chapter belongs to the approved three-volume roadmap.

2. Sequence Validation  
   The chapter is the correct next chapter in the current part.

3. Duplicate Validation  
   The topic has not already been covered.

4. Scope Validation  
   The chapter advances the reader toward Senior/Lead/Architect-level enterprise Java mastery.

5. Template Validation  
   The chapter follows the frozen 18-section chapter structure.

6. Repository Validation  
   The file is placed in the correct volume and part folder.

## Periodic Review

After every 25 generated chapters, perform a roadmap audit:

- Completed chapters
- Remaining chapters
- Deviations
- Duplicate or overlapping content
- Missing topics
- Corrective actions

## Non-Negotiables

- Do not add exercises.
- Do not add unapproved modules.
- Do not change the target audience.
- Do not change the repository structure.
- Do not change the frozen chapter template.
