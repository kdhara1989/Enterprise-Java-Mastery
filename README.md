# Enterprise Java Mastery

Enterprise Java Mastery is a three-volume technical book series for Java developers with 10+ years of experience who want to master enterprise Java engineering, architecture, performance, production readiness, and senior-level interview preparation.

## Target Audience

- Senior Java Developers
- Technical Leads
- Staff Engineers
- Solution Architects
- Enterprise Software Engineers
- Engineers preparing for senior roles in product companies such as Barclays, MasterCard, Visa, JP Morgan Chase, Goldman Sachs, Oracle, Microsoft, Amazon, Google, Adobe, Atlassian, PayPal, Cisco, VMware, and similar organizations.

## Volumes

### Volume I – Java Fundamentals & Enterprise Development

1. Enterprise Java Collections Framework
2. Java Multithreading & Concurrency
3. JVM Internals & Performance Tuning
4. Spring Framework & Spring Boot
5. SQL, Database & Persistence

### Volume II – Enterprise Engineering

6. Microservices
7. Apache Kafka & Messaging
8. Docker, Kubernetes & DevOps
9. Enterprise Design Patterns
10. Java Coding Interview Masterclass
11. Enterprise Java System Design

### Volume III – Enterprise Architecture & Leadership

12. Domain-Driven Design
13. Enterprise Architecture
14. Security

17. Engineering Leadership
