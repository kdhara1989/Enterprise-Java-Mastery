# Enterprise Java Mastery

Enterprise Java Mastery is a three-volume technical book series for Java developers with 10+ years of experience who want to master enterprise Java engineering, architecture, performance, production readiness, and senior-level interview preparation.

This repository is the source of truth for the manuscript.

## Target Audience

This book is written for:

- Java Developers with 10+ years of experience
- Senior Java Engineers
- Technical Leads
- Staff Engineers
- Solution Architects
- Enterprise Software Engineers

The content is aimed at engineers preparing for senior positions in product and enterprise technology companies such as Barclays, MasterCard, Visa, JP Morgan Chase, Goldman Sachs, Oracle, Microsoft, Amazon, Google, Adobe, Atlassian, PayPal, Cisco, VMware, and similar organizations.

## Book Objective

The objective is to transform an experienced Java developer into an engineer capable of:

- Designing enterprise systems
- Building production-grade Java applications
- Understanding JVM internals
- Optimizing performance
- Troubleshooting production issues
- Making architectural decisions
- Leading engineering teams

## Non-Negotiable Rules

- The roadmap is frozen until Version 1.0 is complete.
- The chapter template is frozen.
- No exercises are included.
- Each generated chapter must follow the approved structure.
- Each chapter must be enterprise-focused.
- Each chapter must be suitable for readers with 10+ years of Java experience.
